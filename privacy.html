Privacy Policy

Effective date: October 3, 2026

MLR Portfolio Sync is a private, personal-use application operated solely for the repository owner's own workflow.

Google data accessed

The application may access Google Drive files and folders that the owner has authorized for use by the application's automated workflow. This access is used to read, create, or update project files needed for synchronization and data processing.

How Google data is used

Google user data is used only to perform the synchronization and processing requested by the owner. It is not used for advertising, profiling, or any unrelated purpose.

Storage and security

Project files remain in the owner's Google Drive and private development systems used by the workflow. OAuth credentials are stored as encrypted repository secrets in a private GitHub repository. This public website does not store OAuth credentials or Google Drive data.

Sharing

The application does not sell Google user data and does not share it with third parties for their own independent use. Data may pass through infrastructure providers used to execute the owner's private workflow, solely as necessary to provide that workflow.

Retention and deletion

Files are retained according to the owner's project needs. The owner can revoke the application's Google account access at any time, remove the OAuth credentials from GitHub, and delete project files from Google Drive.

Scope of use

This application is not offered to the public and does not support third-party accounts.

Contact

Questions about this policy may be raised through the public repository that hosts this site.
